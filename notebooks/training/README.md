# notebooks/training

- `phase_2_baselines.ipynb`: TF-IDF logistic regression and XGBoost on engineered features. Calibrated on `val`, thresholds by validation F1, then the locked test, the adversarial set, recall at FPR budgets (overall, per shape, gate rows), bootstrap intervals, slices, and operating points chosen on validation (all rows, and document + agentic rows for the retrieval path). Saves per-row probabilities beside the run so Phase 3 can score the baseline and an ensemble on identical rows.
- `phase_3_text_cnn_bigru.ipynb`: CNN + bidirectional GRU (padding-invariant, packed sequences) with a binary head and a nine-way reason head. Same evaluation, plus the reason-head table, CPU latency, and the **candidates and gate** section: the CNN, the Phase 2 TF-IDF baseline, and their mean ensemble are compared on the test document + agentic rows at every FPR budget; the verdict and the recommended backend go to `gate.json`, which the `src/` package reads by default.

Both read `DATASET_VERSION` from their configuration cell (currently `v4`), assert the manifest and fingerprint before training, and write `models/<run-id>/` and a report folder under `reports/`. The promotion gate is in `docs/PLAN.md` section 4. See `docs/PROCESS.md` section 4.
